## 1. 项目概述

### 1.1 目标
帮助亚马逊卖家快速生成一整套高质量的产品图片，通过AI驱动的方式，大幅提升效率。

### 1.2 核心价值
- 🚀 效率提升：从几小时缩短到几分钟
- 🎨 风格一致：保证整套图片视觉统一
- 📋 模板复用：一次配置，多次使用
- 🤖 AI驱动：使用最先进的图像生成技术

## 2. 功能需求

### 2.1 核心功能清单

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| 产品图上传 | 支持白底产品图上传 | P0 |
| AI引擎选择 | 可选择Stable Diffusion/Midjourney/DALL-E 3等 | P0 |
| 7图批量配置 | 每张图可单独设置参考图和提示词 | P0 |
| 模板系统 | 保存/加载配置模板 | P0 |
| 队列生成 | 逐张生成，显示进度 | P0 |
| 打包导出 | 一键下载全套图片 | P0 |

### 2.2 详细功能说明

#### 2.2.1 产品图上传
- 支持JPG/PNG格式
- 推荐比例1:1（正方形）
- 文件大小限制：建议<20MB

#### 2.2.2 AI引擎选择
- 统一选择一个AI引擎生成所有7张图
- **目的**：保证套图风格一致性
- V1.0支持：
  - Stable Diffusion (推荐)
  - Midjourney
  - DALL-E 3

#### 2.2.3 7图批量配置
- 界面显示7个卡片，对应7张图片
- 每个卡片包含：
  - 参考图上传区域（1-3张）
  - 提示词输入框
  - 预览占位区

#### 2.2.4 模板系统
**保存模板**：
- 输入模板名称
- 保存所有7张图的配置（参考图+提示词+AI选择）
- 存储在本地（localStorage）

**加载模板**：
- 从模板列表选择
- 一键填入所有配置
- 用户只需替换新的产品图

#### 2.2.5 队列生成
- 点击"开始生成"后按顺序处理
- 实时显示进度（当前第几张/共7张）
- 支持：
  - 暂停/继续
  - 跳过某张
  - 失败重试

#### 2.2.6 打包导出
- 生成完成后可预览所有图片
- 支持单独下载某张
- 支持一键打包下载所有7张
- 文件名规范：`product_01.jpg`, `product_02.jpg`...

## 4. 数据模型

### 4.1 TypeScript 类型定义

```typescript
// 产品图配置
interface ProductImageConfig {
  id: string;
  productImage: File | null;        // 白底产品图
}

// 单张图片配置
interface ImageConfig {
  id: number;                      // 1-7
  referenceImages: File[];         // 参考图
  prompt: string;                  // 提示词
  generatedImage: string | null;   // 生成结果 (base64)
  status: 'pending' | 'generating' | 'done' | 'error';
}

// 完整配置
interface GenerationConfig {
  productImage: File | null;
  aiEngine: 'stable-diffusion' | 'midjourney' | 'dalle';
  images: ImageConfig[];           // 长度为7
}

// 模板
interface Template {
  id: string;
  name: string;
  createdAt: number;
  aiEngine: 'stable-diffusion' | 'midjourney' | 'dalle';
  imageConfigs: Array<{
    prompt: string;
    // 注意：模板中不存参考图文件，只存提示词
  }>;
}
```

## 6. 核心流程

### 6.1 完整生成流程

```
1. 用户上传白底产品图
   ↓
2. 选择AI引擎
   ↓
3. (可选) 加载现有模板，或手动配置7张图
   ↓
4. 为每张图设置参考图和提示词
   ↓
5. (可选) 保存配置为模板
   ↓
6. 点击"开始生成"
   ↓
7. 后端队列处理，逐张生成
   ↓
8. 实时更新前端进度和结果
   ↓
9. 全部完成后，用户预览并打包导出
```

### 6.2 AI生成流程 (以Stable Diffusion为例)

```
接收请求
   ↓
准备输入：产品图 + 参考图 + 提示词
   ↓
调用SD API (img2img + ControlNet保持产品形状)
   ↓
轮询API状态
   ↓
获取生成结果
   ↓
返回给前端
```

## 7. API 设计

### 7.1 后端API端点

| 方法 | 路径 | 描述 |
|-----|------|------|
| POST | /api/generate/start | 开始生成任务 |
| GET | /api/generate/status/:id | 查询生成状态 |
| POST | /api/generate/retry | 重试失败任务 |

### 7.2 请求/响应示例

**开始生成请求**
```typescript
POST /api/generate/start
{
  productImage: base64,
  aiEngine: 'stable-diffusion',
  images: [
    { referenceImages: [base64...], prompt: '...' },
    ...
  ]
}
```

**开始生成响应**
```typescript
{
  taskId: 'abc123',
  status: 'started'
}
```
